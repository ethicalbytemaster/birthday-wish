# Cinematic Birthday Website

A premium, visually stunning birthday website crafted for **Riddhi** with emotional storytelling, romantic scenes, and elegant interactive reveals.

## Features

- **Fullscreen Hero Section** with animated gradient title and floating heart particles
- **Glassmorphism Message Slider** with 3-step smooth transitions
- **Interactive Celebration Stage** with fairy lights, music player, and floating balloons
- **Theater Curtain Reveal** with romantic letter and sparkle effects
- **Responsive Memory Gallery** with hover zoom and romantic captions
- **Fully Responsive** single-page layout (mobile + desktop)
- **No frameworks** - pure HTML, CSS, and JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern browser.
3. Replace placeholder images with your real memories.
4. Add your birthday song at `assets/audio/birthday.mp3`.

## Color Theme

- Background: Deep black, burgundy, and wine gradients
- Accent: Neon pink, soft pink, gold
- Text: Warm white with muted pink highlights

## Fonts

- **Playfair Display** - Headlines and titles
- **Dancing Script** - Romantic accent text
- **Montserrat** - Body text

## Deployment

Upload to a public GitHub repository and enable **GitHub Pages** from repository Settings.
